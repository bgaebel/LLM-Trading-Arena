# Experimente

- [templates/experiment.md](templates/experiment.md): Vorlage für Versuchspläne.
- [protocols/](protocols/README.md): versionierte Versuchsdefinitionen.
- [reports/](reports/README.md): Ergebnisse und Interpretation.
